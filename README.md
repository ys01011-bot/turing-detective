## 1. 처음 한 번만: 준비하기

1. 이 폴더(`C:\Users\ys010\dev\turing-detective`)에서 터미널(PowerShell)을 엽니다.
2. 필요한 부품을 설치합니다.

```powershell
npm install
```

3. (선택) 교사 PIN 정하기
   - `.env.example` 파일을 복사해서 이름을 `.env` 로 바꿉니다.
   - `.env` 를 메모장으로 열고 `TEACHER_PIN=` 뒤에 원하는 숫자를 씁니다. 예) `TEACHER_PIN=2580`
   - `.env` 를 만들지 않으면 PIN은 **0000** 입니다. (수업 전에는 꼭 바꾸세요)
   - `.env` 파일은 GitHub에 올라가지 않습니다. API 키도 나중에 여기에 직접 붙여넣습니다.

## 2. 켜기

```powershell
npm start
```

화면에 `튜링 탐정단 서버가 켜졌어요` 가 나오면 성공입니다. 끄려면 터미널에서 `Ctrl + C` 를 누릅니다.

## 3. 주소

| 누가 | 주소 |
|---|---|
| 선생님 (PC·프로젝터) | http://localhost:3000/teacher |

## 4. 수업 순서 (교사 화면 탭)

1. **① 방 만들기**: 모둠 수, 판·바퀴 수, 시간, 판별 주제와 난이도를 고르고 '방 만들기' → 방 코드와 QR이 크게 나옵니다.
2. **② 접속 현황**: 학생 입장과 입장 인사를 확인합니다. 모둠 이동·내보내기 가능. '전체 게임 시작'.
3. **③ 진행**: 모둠별 대화, 마피아(선생님만 보임), 남은 시간. 일시정지·턴 다시·건너뛰기·백업 메시지·투표 마감 버튼.
4. 결과가 나오면 ② 또는 ③에서 '다음 판 시작'.
5. **④ 점수판**: 판별 결과와 점수, 학급 상위 5명.
6. **⑤ 근거 보드**: 학생들의 투표 근거를 경험·감정·책임·겉모습으로 나눠 보여 줍니다. 끌어서 칸을 옮기고, 눌러서 크게 보고 '명탐정 근거상'을 줄 수 있습니다.
7. **⑥ 정리**: '정리 단계 시작'을 누르면 학생 화면이 사후 질문·약속 쓰기로 바뀝니다. 사전·사후 비교 그래프, 약속 게시판.
8. **⑦ 수업 종료**: 모든 대화·근거·점수를 서버에서 지웁니다.

## 5. 수업 내용 바꾸기 (코드 고치지 않기)

`content/` 폴더의 파일을 메모장으로 고치면 됩니다. 서버를 다시 켜지 않아도 다음 판부터 반영됩니다.

| 파일 | 내용 |
|---|---|
| `topic-sets.json` | 주제 세트(바퀴 질문, 단서 지시, 예시, 백업 메시지) |
| `spelling-rules.json` | 맞춤법 자동 보정 목록 `[틀린 말, 바른 말]` |
| `banned-words.json` | 금칙어 |
| `class-questions.json` | 사전·사후 질문, 약속 안내, 역할 안내 문구, 정리 발문 |
| `prompts.json` | AI에게 보낼 지시문 틀 (다음 단계에서 사용) |

## 6. 혼자 시험해 보기 (개발용)

서버를 켠 채로 다른 터미널에서:

```powershell
npm run sim -- --groups 4 --players 6
```

봇 24명이 2판을 끝까지 진행합니다. 이미 만든 방 한 모둠에 봇만 넣으려면 `npm run sim -- --code 123456 --group 0 --players 5`.

```powershell
npm test
```

맞춤법 보정·금칙어 점검(서버 없이 실행). `npm run test:controls` 는 서버를 켠 상태에서 교사 조작(일시정지, 건너뛰기 등)을 점검합니다.
